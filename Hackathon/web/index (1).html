How it works (OS concepts)

1. Split
The file is divided into fixed-size chunks (the work units placed in a shared task queue).
2. Parallel analyze
N worker threads pull chunks from the queue (producer–consumer) and scan lines with pattern rules.
3. Synchronize
Each thread keeps private counters (no data races); the main thread merges them — the role a mutex plays in pthreads.
4. Report
Merged totals feed charts, IP statistics and the event explorer.

Equivalent C (pthreads) design

pthread_mutex_t lock = PTHREAD_MUTEX_INITIALIZER;
Stats global;                       // shared result

void *worker(void *arg) {
    Chunk *c; Stats local = {0};
    while ((c = queue_pop()) != NULL)      // thread-safe queue
        for (char *ln = c->start; ln < c->end; ln = next_line(ln))
            classify(ln, &local);          // ERROR / WARN / suspicious
    pthread_mutex_lock(&lock);             // critical section
    merge(&global, &local);
    pthread_mutex_unlock(&lock);
    return NULL;
}
// main: split file -> queue_push(chunks) -> pthread_create x N
//       -> pthread_join x N -> print_report(&global)
